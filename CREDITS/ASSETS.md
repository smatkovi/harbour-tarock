# Asset credits

This file lists, for every image, font and text that ships with harbour-tarock,
its source, URL, retrieval date, licence, author and the changes that were made
to it. `CreditsPage.qml` renders it inside the app, so keep it readable as
plain text.

Until the asset pipeline lands (milestone M8, `docs/design.md` §10) the only
asset in the repository is the placeholder application icon.

## Rule specifications

The four rule specifications in `docs/` (`koenigrufen.md`, `hungarian.md`,
`tapptarock.md`, `strohmandeln.md`) are the normative sources for everything
the engine enforces; the app's About page names them. Their own provenance is
documented in their headers.
